# Anything Humanly Possible

This is the production web application for **Anything Humanly Possible**, powered by React, Vite, TailwindCSS, and Supabase.

The design is based on the original Figma project: [Anything Humanly Possible](https://www.figma.com/design/sFDUFgzNR8UaS3Pwjykuj1/Anything-Humanly-Possible).

## Features

- **Personal Growth Command Center & Dashboard**
- **Curated Mastery Space & Mentorship Courses**
- **Interactive AI Mentors with Voice & Guided Lessons**
- **Real-Time Supabase Cloud Sync (Auth, Profiles, Progress, & Community Stories)**
- **Ambient Sound Engine & Multi-Gesture Interactions**

## Development

```bash
# Install dependencies
npm install

# Run local development server
npm run dev
```

## Production Build

```bash
npm run build
```
